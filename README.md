A short, funny rant about an everyday annoyance — a self-checkout machine
that accuses an innocent shopper of smuggling — written for the
[Angry Judge: The Short Rant Contest](https://make.fun/c/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046)
on [make.fun](https://make.fun).

## How it works

`main.ts` is a dependency-free Node 22 program. It writes one deterministic
text (373 characters, no trailing newline) to `/output/entry.txt`:

```sh
node main.ts            # writes /output/entry.txt
node main.ts <outDir>   # writes <outDir>/entry.txt
```

## The rant

> Self-checkout, you smug little robot. I scanned one bag of rice and you
> screamed 'unexpected item in the bagging area' like I had smuggled a live
> goat. Then you froze, summoned assistance, and made me stand there while
> a teenager pressed a single button to forgive me. I did everything right.
> You panicked. Never again — I would rather queue behind the man paying
> in coins.
